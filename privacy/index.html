개인정보 처리방침

QuickBoard · 시행일 2026-05-01

제1조 (수집하는 개인정보 항목)

QuickBoard(이하 ‘서비스’)는 별도의 회원가입이나 로그인 절차 없이 누구나 무료로 이용할 수 있는 보드게임 점수계산 서비스입니다. 서비스 운영자는 이용자로부터 직접 수집하는 개인정보가 없습니다.

다만, 서비스 이용 과정에서 다음 정보가 자동으로 수집될 수 있습니다.

  • IP 주소, 쿠키, 광고 식별자(IDFA/AAID), 단말 기종, 브라우저 정보, 서비스 이용 기록
  • 위 정보는 Google AdSense / AdMob 등 광고 파트너를 통해 자동 수집되어 광고 게재 및 통계 목적에 활용됩니다.

제2조 (개인정보의 처리 목적)

자동 수집되는 정보는 다음 목적으로 처리됩니다.

  • 비개인화 광고 게재(맞춤형 광고 추적은 사용하지 않음)
  • 서비스 안정성 확인, 부정 이용 방지, 통계 분석

제3조 (보유 및 이용 기간)

광고 파트너가 자동 수집하는 정보는 해당 파트너의 정책에 따라 보유 및 처리됩니다. 자세한 내용은 다음을 참고하시기 바랍니다.

  • Google 개인정보처리방침: policies.google.com/privacy

점수 입력 데이터 등 게임 진행 정보는 외부 서버로 전송되지 않으며, 사용자 기기 내부에서만 임시 보관됩니다.

제4조 (개인정보의 제3자 제공)

서비스는 이용자로부터 직접 수집한 개인정보가 없으므로 제3자에게 제공하는 개인정보가 없습니다. 광고 파트너의 자동 수집 정보는 해당 파트너의 정책을 따릅니다.

제5조 (개인정보의 처리 위탁)

현재 서비스는 별도의 개인정보 처리 위탁 업무를 두고 있지 않습니다. 사이트 호스팅은 GitHub Pages를 통해 제공됩니다.

제6조 (이용자의 권리)

광고 식별자 추적 거부 및 비개인화 광고 설정은 단말 또는 브라우저 설정을 통해 변경할 수 있습니다.

  • iOS: 설정 → 개인정보 보호 및 보안 → 추적 → 추적 요청 허용 끄기
  • Android: 설정 → Google → 광고 → 광고 ID 재설정 / 맞춤설정 사용 안 함
  • 웹: 브라우저 설정에서 쿠키 차단

제7조 (개인정보 보호책임자 및 문의처)

개인정보 처리 관련 문의는 다음 채널로 접수해 주시기 바랍니다.

  • 지원 페이지: quickboard.club/support
  • 카카오톡 오픈채팅: open.kakao.com/o/sEf7kJsi

제8조 (권익침해 구제 방법)

개인정보 침해에 대한 신고나 상담이 필요한 경우 아래 기관에 문의하실 수 있습니다.

  • 개인정보 침해신고센터(한국인터넷진흥원): privacy.kisa.or.kr / (국번없이) 118
  • 개인정보 분쟁조정위원회: www.kopico.go.kr / 1833-6972
  • 대검찰청 사이버수사과: spo.go.kr
  • 경찰청 사이버수사국: cyberbureau.police.go.kr / 182

제9조 (개인정보 처리방침의 변경)

이 개인정보 처리방침의 내용 추가, 삭제 및 수정이 있을 경우 본 페이지를 통해 사전 공지합니다.
