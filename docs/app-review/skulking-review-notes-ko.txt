안녕하세요. 요청하신 정보를 아래와 같이 전달드립니다.

1. 앱 화면 흐름
앱은 게임 설정, 게임 진행, 최종 결과 세 화면으로 구성됩니다. 화면 녹화 영상이 필요하시면 요청해 주시면 전달드리겠습니다.

- 게임 설정: 앱 실행 직후 나타납니다. 플레이어 수를 2~8명 중 선택하고 이름을 입력한 뒤 "게임 시작"을 누릅니다. 이름은 비워도 됩니다.
- 게임 진행: 플레이어마다 예측승, 획득승, 보너스를 입력하면 라운드 점수가 즉시 계산됩니다. 모든 플레이어의 획득승 합계가 현재 라운드 수와 일치할 때만 "다음 라운드" 버튼이 나타납니다. 카드 게임 규칙상 한 라운드의 트릭 수는 라운드 번호와 같아야 하므로, 잘못된 점수로 진행되지 않도록 막아둔 것입니다. 총 10라운드이며 "게임 종료"로 언제든 끝낼 수 있습니다.
- 최종 결과: 총점 순 순위와 라운드별 점수를 보여줍니다. "결과 공유"를 누르면 결과 이미지를 iOS 공유 시트로 공유하거나 사진 앨범에 저장할 수 있습니다.

앱 실행 직후 추적 권한 안내(ATT)가 표시되며, 거부해도 모든 기능을 동일하게 사용할 수 있습니다. 배너 광고는 화면 상단에 고정 노출됩니다.

2. 테스트 기기 및 OS
- iPhone 12 Pro, iOS 26.6.1
- 최소 지원 버전: iOS 17.0

3. 앱의 목적과 대상 사용자
보드게임 Skull King을 플레이할 때 라운드별 점수를 계산하고 기록하는 점수 계산 보조 앱입니다. 카드 게임을 플레이하는 기능은 없으며, 오프라인에서 카드로 게임을 진행하는 동안 점수만 대신 계산합니다.
대상 사용자는 친구, 가족, 보드게임 모임에서 Skull King을 즐기는 플레이어입니다. 예측한 트릭 수와 실제 획득한 트릭 수, 보너스를 조합해 라운드마다 계산식이 달라지기 때문에 수동 계산이 번거롭습니다. 이 앱은 2~8명, 10라운드의 점수와 누적 총점, 최종 순위를 자동으로 계산합니다.

4. 앱 접근 및 주요 기능 사용 방법
로그인, 회원가입, 계정 삭제, 유료 결제, 구독, 별도 샘플 파일이 모두 필요하지 않습니다. 설치 후 바로 모든 기능을 사용할 수 있으며 네트워크 연결도 필요하지 않습니다. 사용 방법은 1번 항목을 참고해 주십시오.

5. 외부 서비스, 도구, 플랫폼
점수 계산과 기록은 모두 기기 내에서 로컬로 처리되며, 게임 데이터를 외부로 전송하지 않습니다.
- Google AdMob: 무료 앱 운영을 위한 배너 광고
- App Tracking Transparency: 맞춤형 광고 제공 여부 확인. 거부 시 비맞춤형 광고로 전환되며 기능 제한은 없습니다.
- 사진 앨범 추가 권한: 결과 이미지를 앨범에 저장할 때만 요청됩니다.

6. 지역별 기능 차이
지역에 따른 기능 또는 콘텐츠 차이가 없습니다. 한국어와 영어를 지원하며 기기 언어 설정에 따라 표시됩니다.

7. 규제 산업 또는 보호된 제3자 자료 관련
도박, 금융, 의료, 법률 등 규제 산업의 서비스를 제공하지 않습니다. 실제 금전이 오가는 요소, 베팅, 확률형 아이템, 앱 내 구매가 없습니다.
카드 이미지, 규칙서 원문, 공식 아트워크 등 보호된 제3자 자료를 포함하지 않으며, 사용자가 직접 입력한 숫자만 계산합니다.
