안녕하세요. 요청하신 정보를 아래와 같이 전달드립니다.

1. 앱 화면 흐름
앱은 게임 설정, 점수표, 최종 결과 세 화면으로 구성됩니다. 화면 녹화 영상이 필요하시면 요청해 주시면 전달드리겠습니다.

- 게임 설정: 앱 실행 직후 나타납니다. 플레이어 수를 2~8명 중 조절하고 이름을 입력한 뒤 "게임 시작"을 누릅니다. 이름은 비워도 됩니다.
- 점수표: 12개 카테고리와 플레이어로 이루어진 표입니다. 입력 순서에 제약이 없어 어느 칸이든 눌러 입력할 수 있습니다. 칸을 누르면 하단에서 입력 시트가 올라오며, 카테고리에 따라 두 가지 방식으로 나뉩니다.
  - 에이스~풀하우스: 숫자로 직접 입력합니다. 카테고리마다 상한이 다르며, 상한을 넘는 값을 넣으면 자동 변환 안내가 표시되고 상한값으로 저장됩니다.
  - 스몰 스트레이트, 라지 스트레이트, 요트: 성공 시 점수가 정해져 있어 숫자 입력 대신 "0점"과 "해당 점수" 두 버튼 중에서 선택합니다.
  상단 6개 카테고리의 소계가 63점 이상이 되면 보너스 35점이 자동 가산되고 총점이 갱신됩니다. 입력한 칸을 다시 눌러 언제든 수정할 수 있으며, "게임 종료"로 언제든 끝낼 수 있습니다.
- 최종 결과: 총점 순 순위를 보여줍니다. "결과 공유"를 누르면 결과 이미지를 iOS 공유 시트로 공유하거나 사진 앨범에 저장할 수 있습니다.

앱 실행 직후 추적 권한 안내(ATT)가 표시되며, 거부해도 모든 기능을 동일하게 사용할 수 있습니다. 배너 광고는 화면 상단에 고정 노출됩니다.

2. 테스트 기기 및 OS
- iPhone 12 Pro, iOS 26.6.1
- 최소 지원 버전: iOS 17.0

3. 앱의 목적과 대상 사용자
주사위 게임 요트 다이스(Yacht Dice)를 플레이할 때 카테고리별 점수를 기록하고 합계를 계산하는 점수 계산 보조 앱입니다. 주사위를 굴리는 기능은 없으며, 실제 주사위로 게임을 진행하는 동안 점수표만 대신 관리합니다.
대상 사용자는 친구, 가족, 보드게임 모임에서 요트 다이스를 즐기는 플레이어입니다. 12개 카테고리를 각각 한 번씩만 채우고 카테고리마다 상한 점수가 다른 데다 상단 보너스 조건까지 따져야 해서 수동 계산이 번거롭습니다. 이 앱은 2~8명의 소계와 보너스, 총점, 최종 순위를 자동으로 계산합니다.

4. 앱 접근 및 주요 기능 사용 방법
로그인, 회원가입, 계정 삭제, 유료 결제, 구독, 별도 샘플 파일이 모두 필요하지 않습니다. 설치 후 바로 모든 기능을 사용할 수 있으며 네트워크 연결도 필요하지 않습니다. 사용 방법은 1번 항목을 참고해 주십시오.

5. 외부 서비스, 도구, 플랫폼
점수 계산과 기록은 모두 기기 내에서 로컬로 처리되며, 게임 데이터를 외부로 전송하지 않습니다.
- Google AdMob: 무료 앱 운영을 위한 배너 광고
- App Tracking Transparency: 맞춤형 광고 제공 여부 확인. 거부 시 비맞춤형 광고로 전환되며 기능 제한은 없습니다.
- 사진 앨범 추가 권한: 결과 이미지를 앨범에 저장할 때만 요청됩니다.

6. 지역별 기능 차이
지역에 따른 기능 또는 콘텐츠 차이가 없습니다. 한국어와 영어를 지원하며 기기 언어 설정에 따라 표시됩니다.

7. 규제 산업 또는 보호된 제3자 자료 관련
도박, 금융, 의료, 법률 등 규제 산업의 서비스를 제공하지 않습니다. 실제 금전이 오가는 요소, 베팅, 확률형 아이템, 앱 내 구매가 없습니다. 주사위를 굴리는 기능이 없어 무작위 결과를 생성하지 않습니다.
주사위 이미지, 규칙서 원문, 공식 아트워크 등 보호된 제3자 자료를 포함하지 않으며, 사용자가 직접 입력한 숫자만 계산합니다.
