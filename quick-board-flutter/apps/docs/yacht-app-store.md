### 설명 (Description, 4000자 이내)

```
요트 다이스 점수, 더 이상 머리로 계산하지 마세요.

요트다이스 점수계산은 보드게임 모임에서 자주 즐기는 요트 다이스의
점수를 자동으로 계산하고 기록해주는 점수판 앱입니다.
종이와 펜 없이, 화면을 손가락으로 톡톡 두드리는 것만으로
12 라운드 전 과정을 깔끔하게 진행할 수 있습니다.

[이런 분께 추천합니다]
- 친구·가족과 보드게임을 즐기는 모임 호스트
- 점수 계산이 번거롭거나 자주 실수가 나는 분
- 게임 결과를 공유하고 기록으로 남기고 싶은 분

[주요 기능]
- 2명에서 8명까지 동시 플레이 지원
- 12개 카테고리 모두 지원
  · 에이스 / 듀얼 / 트리플 / 쿼드 / 펜타 / 헥사
  · 초이스 / 포커 / 풀하우스
  · 스몰 스트레이트 / 라지 스트레이트 / 요트
- 상단 합계 63점 달성 시 보너스 35점 자동 가산
- 카테고리별 최대 점수 안내와 잘못된 입력 자동 보정
- 라운드 진행 상황 한눈에 확인
- 게임 종료 시 최종 순위 자동 계산
- 결과 텍스트 한 번의 탭으로 공유
- 다크 테마로 눈이 편안한 디자인
- 한국어, English 지원
- 인터넷 연결 없이도 모든 점수 계산 가능

[사용 방법]
1. 플레이어 인원과 이름을 입력합니다.
2. 게임을 시작하고, 각 라운드마다 카테고리를 골라 점수를 입력합니다.
3. 12 라운드가 끝나면 자동으로 최종 순위를 보여드립니다.
4. 결과를 공유하거나 다시 한 판 시작합니다.

[안내]
본 앱은 보드게임 점수 계산 보조 도구이며,
실제 주사위 굴림은 직접 진행합니다.
하단의 작은 배너 광고가 운영을 도와줍니다.

즐거운 보드게임 시간 되세요.
```

### Description (4000 chars)

```
Stop doing Yacht Dice math in your head.

YachtDice Score is a clean, lightweight score pad
for the classic dice game enjoyed at game nights everywhere.
No more crumpled paper, no more counting errors.
Play all 12 rounds with smooth, finger-friendly score entry.

[Perfect for]
- Game night hosts playing with friends or family
- Anyone tired of doing dice math on paper
- Players who want to save and share their results

[Features]
- Supports 2 to 8 players simultaneously
- All 12 categories included
  - Aces, Duals, Triples, Quads, Penta, Hexa
  - Choice, Poker (Four of a Kind), Full House
  - Small Straight, Large Straight, Yacht
- Auto +35 bonus when upper section reaches 63
- Max-score hints prevent invalid entries
- Real-time progress and running totals
- Final ranking shown automatically at game end
- One-tap result sharing
- Easy-on-the-eyes dark theme
- Korean, English supported
- Works fully offline. No signup required.

[How it works]
1. Choose the number of players and enter names.
2. Start the game and tap a category each round to enter the score.
3. After 12 rounds, see the final ranking instantly.
4. Share the result or start a new game.

[Notes]
This app is a scorekeeping companion;
you still roll the physical dice yourself.
A small banner ad helps keep the app free.

Enjoy your game night.
```
